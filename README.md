# FinScope Pro

**FinScope Pro** — desktop-приложение на Python для финансового и операционного анализа товарного портфеля.

Проект объединяет анализ продаж, unit economics, P&L, прогнозирование спроса, ABC-XYZ классификацию, анализ ценовой эластичности, сценарное моделирование и формирование практических рекомендаций для бизнеса.

> Проект находится в стадии развития. Расчёты и прогнозы следует использовать как аналитическую поддержку для принятия решений, а не как замену финансовой экспертизе.

## Возможности

- 📊 Дашборд с ключевыми финансовыми показателями.
- 📥 Импорт данных из **Excel, CSV и JSON**.
- 🔗 Импорт данных из **Google Sheets** при наличии соответствующих credentials.
- 🧹 Автоматическое определение колонок, очистка дат и денежных значений.
- 💰 Расчёт unit economics, маржинальности, точки безубыточности и P&L.
- 🤖 Прогнозирование спроса с ансамблем:
  - Linear Regression;
  - Random Forest;
  - Gradient Boosting.
- 📈 Оценка качества прогноза на отложенной выборке.
- 🧮 Расчёт ценовой эластичности по историческим данным.
- 🧩 ABC-XYZ анализ товарного портфеля.
- 🎯 Классификация позиций по доле выручки и прогнозному росту.
- 💡 Автоматическая генерация рекомендаций: рост выпуска, изменение цены, поддержание объёма, сокращение или вывод позиции.
- 💵 ROI рекомендаций: требуемый капитал, дополнительная прибыль, срок окупаемости и уровень риска.
- 🔬 Сценарный анализ: оптимистичный, реалистичный и пессимистичный сценарии.
- 🧪 Stress-test по изменению спроса.
- 💧 Анализ оборотного капитала и Cash Conversion Cycle.
- 🧱 План потребности в сырье.
- 🗂️ История проектов в SQLite.
- 📄 Экспорт результатов в PDF и Excel.
- 🧪 Встроенный self-test для проверки основных расчётов.

## Архитектура

Основная логика проекта находится в `ml.py`.

Ключевые компоненты:

```text
Input data
    │
    ├── Excel / CSV / JSON
    └── Google Sheets
          │
          ▼
   Data preparation
          │
          ▼
   Financial Engine
   ├── Unit Economics
   ├── P&L
   ├── Break-even
   └── Working Capital
          │
          ├───────────────┐
          ▼               ▼
 Demand Forecast      Portfolio Analysis
 LR + RF + GBR        ABC-XYZ / BCG-like
          │               │
          └───────┬───────┘
                  ▼
          Recommendation Engine
                  │
          ┌───────┴────────┐
          ▼                ▼
       ROI / Risk      Scenarios / Stress
          │                │
          └───────┬────────┘
                  ▼
             Reports
          PDF / Excel / UI
```

## Установка

Рекомендуется Python **3.10+**.

```bash
git clone https://github.com/okokhov-art/finscope-pro.git
cd finscope-pro

python -m venv .venv
```

### Windows

```bash
.venv\Scripts\activate
pip install -r requirements.txt
python ml.py
```

### macOS / Linux

```bash
source .venv/bin/activate
pip install -r requirements.txt
python ml.py
```

> Для Linux может потребоваться системный пакет Tkinter. На Windows Tkinter обычно входит в стандартную установку Python.

## Быстрый старт

После запуска приложение позволяет:

1. загрузить собственный Excel/CSV/JSON-файл;
2. либо использовать встроенный demo dataset;
3. настроить финансовые параметры;
4. запустить расчёт;
5. изучить KPI, P&L, прогноз спроса, портфель, ABC-XYZ и рекомендации;
6. экспортировать отчёт или план действий.

Для демонстрации приложение умеет генерировать синтетический набор данных.

## Формат входных данных

Минимально ожидаются поля:

| Поле | Назначение |
|---|---|
| `Дата` | дата операции |
| `Товар` | наименование товара |
| `Количество единиц` | объём продаж/производства |
| `Цена за штуку` | цена единицы |

Опционально:

| Поле | Назначение |
|---|---|
| `Компоненты` | состав товара для расчёта стоимости сырья |

Приложение умеет автоматически сопоставлять типовые русские и английские названия колонок.

### Сырьё

Для расчёта себестоимости можно добавить в Excel лист `Сырьё` с ценами компонентов.

Пример:

```text
Товар       Цена за штуку
Сырьё_A     120
Сырьё_B     80
Сырьё_C     45
```

Рецептура товара может выглядеть так:

```text
Сырьё_A 2 Сырьё_B 3
```

## Прогнозирование спроса

При достаточном количестве исторических данных используется ансамбль моделей:

```text
Linear Regression
        +
Random Forest
        +
Gradient Boosting
        ↓
Weighted Ensemble
```

Используются лаговые признаки, календарные признаки, скользящие средние, стандартное отклонение и оценка тренда.

Если исторических данных недостаточно, приложение использует fallback на историческое среднее и не придумывает метрику точности.

## Финансовая модель

В проекте рассчитываются:

- выручка;
- COGS;
- variable OPEX;
- gross profit;
- EBITDA;
- налог;
- net profit;
- net margin;
- contribution margin;
- break-even;
- working capital;
- cash conversion cycle.

Также реализованы сценарии изменения спроса и оценка потребности в оборотном капитале.

## ABC-XYZ

ABC классифицирует позиции по накопленной доле выручки.

XYZ оценивает вариативность спроса через коэффициент вариации.

На пересечении классов формируется практическая рекомендация по управлению запасами.

## Ценовая эластичность

Если исторических данных достаточно, эластичность оценивается через регрессию:

```text
ln(Q) ~ ln(P)
```

Результат принимается только при достижении заданного порога R². В противном случае используется значение из настроек, которое явно помечается как заданное пользователем.

## Self-test

Для запуска встроенных проверок:

```bash
python ml.py --selftest
```

Self-test проверяет, в частности:

- автоматическое определение колонок;
- миграцию SQLite-схемы;
- запрет неявных цен сырья;
- запуск demo-анализа;
- базовые финансовые расчёты;
- согласованность точки безубыточности;
- работу плана действий;
- наличие методики и сценариев;
- базовые проверки прогноза.

## Ограничения

Проект не является готовой системой промышленного финансового планирования. Особенно важно самостоятельно проверять:

- качество исходных данных;
- корректность себестоимости;
- налоговые предположения;
- финансовые параметры;
- интерпретацию прогноза спроса;
- причинность между ценой и объёмом продаж.

ML-прогнозы являются аналитической оценкой и не гарантируют будущий спрос.

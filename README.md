FinScope Pro

FinScope Pro — desktop-приложение на Python для финансового и операционного анализа товарного портфеля.

Проект объединяет анализ продаж, unit economics, P&L, прогнозирование спроса, ABC-XYZ классификацию, анализ ценовой эластичности, сценарное моделирование и формирование практических рекомендаций для бизнеса.

Проект находится в стадии развития. Расчёты и прогнозы следует использовать как аналитическую поддержку для принятия решений, а не как замену финансовой экспертизе.

Установка

Рекомендуется Python 3.10+.

git clone https://github.com/okokhov-art/finscope-pro.git
cd finscope-pro

python -m venv .venv

Windows

.venv\Scripts\activate
pip install -r requirements.txt
python ml.py

macOS / Linux

source .venv/bin/activate
pip install -r requirements.txt
python ml.py

Для Linux может потребоваться системный пакет Tkinter. На Windows Tkinter обычно входит в стандартную установку Python.

Сырьё

Для расчёта себестоимости можно добавить в Excel лист Сырьё с ценами компонентов.

Пример:

Сырьё_A     120
Сырьё_B     80
Сырьё_C     45

Рецептура товара может выглядеть так:

Сырьё_A 2 Сырьё_B 3

Прогнозирование спроса

При достаточном количестве исторических данных используется ансамбль моделей:

Linear Regression
        +
Random Forest
        +
Gradient Boosting
        ↓
Weighted Ensemble

Используются лаговые признаки, календарные признаки, скользящие средние, стандартное отклонение и оценка тренда.

Если исторических данных недостаточно, приложение использует fallback на историческое среднее и не придумывает метрику точности.

Финансовая модель

В проекте рассчитываются:

выручка;

COGS;

variable OPEX;

gross profit;

EBITDA;

налог;

net profit;

net margin;

contribution margin;

break-even;

working capital;

cash conversion cycle.

Также реализованы сценарии изменения спроса и оценка потребности в оборотном капитале.

ABC-XYZ

ABC классифицирует позиции по накопленной доле выручки.

XYZ оценивает вариативность спроса через коэффициент вариации.

На пересечении классов формируется практическая рекомендация по управлению запасами.

Ценовая эластичность

Если исторических данных достаточно, эластичность оценивается через регрессию:

ln(Q) ~ ln(P)

Результат принимается только при достижении заданного порога R². В противном случае используется значение из настроек, которое явно помечается как заданное пользователем.

Self-test

Для запуска встроенных проверок:

python ml.py --selftest

Self-test проверяет, в частности:

автоматическое определение колонок;

миграцию SQLite-схемы;

запрет неявных цен сырья;

запуск demo-анализа;

базовые финансовые расчёты;

согласованность точки безубыточности;

работу плана действий;

наличие методики и сценариев;

базовые проверки прогноза.

Ограничения

Проект не является готовой системой промышленного финансового планирования. Особенно важно самостоятельно проверять:

качество исходных данных;

корректность себестоимости;

налоговые предположения;

финансовые параметры;

интерпретацию прогноза спроса;

причинность между ценой и объёмом продаж.

ML-прогнозы являются аналитической оценкой и не гарантируют будущий спрос.
